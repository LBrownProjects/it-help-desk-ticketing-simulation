# IT Help Desk Ticketing System Simulation

## Project Overview

This project simulates the help-desk workflow of a fictional healthcare office. It demonstrates how technical support requests are documented, prioritized, troubleshooted, resolved, and escalated.

> **Important:** All organizations, users, incidents, and results in this project are fictional. No real patient or confidential information is included.

## Project Purpose

I created this guided learning project to develop practical knowledge of:

- Help-desk ticket management
- Customer communication
- Windows and Microsoft 365 support
- Account-access troubleshooting
- Ticket prioritization and escalation
- Security and privacy awareness
- IT service metrics
- Project-management fundamentals
